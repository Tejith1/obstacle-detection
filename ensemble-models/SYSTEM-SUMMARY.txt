## 🚀 Quick Start (3 Steps)

### Step 1: Setup (One Time)
```powershell
cd ensemble-models
.\setup.ps1        # Wait 2-5 minutes
```

### Step 2: Start Backend
```powershell
cd ensemble-models\backend
.\venv\Scripts\Activate.ps1
python app.py
```

### Step 3: Start Frontend
```powershell
cd ensemble-models\frontend
npm start
```

**Then open:** http://localhost:3000

## 📚 Model Information

### Model 1: YOLOv5 (Obstacle Detection)
- **Source:** obstacle-detection/best.pt
- **Type:** YOLOv5
- **Purpose:** General obstacle detection
- **Speed:** Very fast ⚡
- **Use:** Best for real-time on low-spec hardware

### Model 2: YOLO11n (VisDrone, Nano)
- **Source:** v1-1/best.pt
- **Training:** 30 epochs, imgsz 640
- **Type:** YOLO11 Nano
- **Purpose:** Fast, lightweight detection
- **Speed:** Fastest of VisDrone models ⚡⚡
- **Use:** Mobile/edge deployment, real-time

### Model 3: YOLO11m (VisDrone, Medium)
- **Source:** v1-2/best.pt
- **Training:** 50 epochs, imgsz 640, SGD optimizer
- **Type:** YOLO11 Medium
- **Purpose:** Balanced accuracy-speed
- **Speed:** Good balance ⚡✨
- **Use:** Production systems, best recommend

### Model 4: Custom YOLO (Results)
- **Source:** results.zip
- **Training:** Custom hyperparameters
- **Type:** YOLO (Ultralytics)
- **Purpose:** Alternative/experimental
- **Speed:** Similar to Model 3
- **Use:** Comparison, testing different training configs
